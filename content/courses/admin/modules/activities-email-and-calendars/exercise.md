## Scenario

Khanyisa Solar's reps forget follow-ups and managers cannot see customer contact history. Installers need a shared calendar of site visits.

## Your goal

Set up activities, calendars and email so follow-ups are visible and easy.

## Before you start

- A Developer Edition org or Trailhead Playground.
- A few test contacts and an opportunity.

## What to build

1. Create a **task** "Send quote" and an **event** "Site visit", both linked to a contact (Name) and an opportunity (Related To).
2. Make the task **recurring** weekly and an event **multi-day**.
3. Create a **shared activity** with two contacts.
4. Add the **Activity Timeline** to the Opportunity page and the **Log a Call** quick action.
5. Create a **public calendar** "Site Visits" and share it with the installer role.
6. Create a **Lightning email template** with merge fields and a letterhead, and send an email from the opportunity.
7. Set up the Outlook or Gmail integration (or Einstein Activity Capture) in a test org and sync one email.

## What you should see when you are done

- [ ] The task appears on the timeline and the event on the calendar.
- [ ] The merge fields show the contact's name.
- [ ] The public calendar shows site visits.
- [ ] Activities appear on both contacts' timelines.

## Check your understanding

- [ ] What is the difference between Name and Related To?
- [ ] Which activity type appears as a time block?
- [ ] Why might a merge field show blank?

## Stretch goal

Create a dashboard of overdue tasks by owner.
