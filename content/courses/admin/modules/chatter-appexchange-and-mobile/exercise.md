## Scenario

Khanyisa Solar's deal conversations live in WhatsApp. Management wants announcements to reach everyone, a private place for the sales leadership, an e-signature tool for quotes, and a mobile experience for installers.

## Your goal

Set up collaboration, an installed app and a focused mobile experience.

## Before you start

- A Developer Edition org or Trailhead Playground.
- Three test users.

## What to build

1. Enable **Chatter**, then create a **broadcast-only** group "Company News", a **private** group "Sales Leadership" and an **unlisted** group "Installers".
2. Turn on **feed tracking** for Opportunity and track Stage and Amount.
3. Post a question on an opportunity, @mention a colleague and mark a **best answer**.
4. Upload a file, share it with a link and upload a new version.
5. Install a **free AppExchange app** in a sandbox or developer org for admins only, then assign it to a profile.
6. Review the **mobile navigation menu**, add a **compact layout** and two **mobile actions** for the Installation object.
7. Log into the mobile app (or the mobile preview) as an installer and log a call.

## What you should see when you are done

- [ ] Only managers can post in the broadcast group.
- [ ] Stage changes appear in the opportunity feed.
- [ ] The installed app is visible only to the profile you chose.
- [ ] The installer can log a call from the phone.

## Check your understanding

- [ ] Which group type is hidden from search?
- [ ] What is the difference between a managed and an unmanaged package?
- [ ] How many fields can feed tracking follow on one object?

## Stretch goal

Create a Chatter topic strategy (three topics) and a post template for deal wins.
