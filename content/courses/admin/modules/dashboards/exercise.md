**Watch the walkthrough above, then do the exercise yourself in your own org.** The video shows every click.

## Scenario

The Khanyisa Solar sales director wants one page she can open on Monday morning. Regional managers want to see **only their own region**, and she wants to see everything.

## Your goal

Build a dashboard from your earlier reports and make it show the right data to the right people.

## Before you start

- A Developer Edition org or Trailhead Playground.
- The reports from the previous exercise (pipeline by stage and owner, and others).
- Two test users in different roles, with different records.

## What to build

1. A dashboard **Sales Monday** in a shared folder.
2. A **chart** of pipeline by stage, a **gauge** of this quarter's closed amount against a target, a **metric** for total open pipeline, and a **table** of the top five open deals.
3. Set the **running user** to a specific user who can see all records. Log in as the other test user and compare.
4. Save a copy as **Sales Monday (Dynamic)**, running as the logged-in user. Log in as the regional manager and compare.
5. Add a **dashboard filter** for Region or Owner.
6. Schedule a refresh on the first dashboard. Check that the option is not available on the dynamic one.
7. Add a **subscription** for the sales director.

## What you should see when you are done

- [ ] The specific-user dashboard shows the same numbers to everyone.
- [ ] The dynamic dashboard shows each viewer only their own records.
- [ ] The filter changes every component.
- [ ] You can explain which dashboard to use for the director and which for the managers.

## Check your understanding

- [ ] Why did the regional manager see more data on the first dashboard than in a report they ran?
- [ ] What happens to your scheduled refresh when you switch to a dynamic dashboard?
- [ ] Which reports could you not use as a source?

## Stretch goal

Create a second dashboard filtered by Product Family and add a chart that uses a **matrix** report.
